# Location data

`locations.json` is the Municipality/City list behind the address form, with a
latitude/longitude for each one. The server loads it once (see
`utils/locations.js`) - nothing looks anything up online while someone is
registering, so picking a place can't fail for want of a service.

The file is generated by `scripts/buildLocations.js`, not typed by hand, and it
has no barangay-level data: an address is a province and a municipality/city,
and its coordinates are that city's own centre point.

## The service area

**AniSave serves Pangasinan only.** The file holds that one province and its 48
municipalities and cities, and nothing else - which is what enforces the
restriction. There is no filtering anywhere else to get wrong: an address
outside the service area simply has no code to be picked by, so `resolveAddress`
rejects it whatever a request claims. The province is therefore not a choice on
the form; it is shown fixed, from `GET /api/locations/service-area`.

To serve somewhere else as well, add its name to `SERVICE_PROVINCES` in
`scripts/buildLocations.js` and rebuild. Nothing in the client hard-codes
"Pangasinan".

## Where it comes from

| Data | Source | Licence |
| --- | --- | --- |
| Provinces and cities/municipalities, with their PSGC codes | Philippine Standard Geographic Code (Philippine Statistics Authority), via <https://psgc.gitlab.io/api> | Public government data |
| Coordinates of each city/municipality | [Wikidata](https://www.wikidata.org), matched by PSGC code | CC0 |
| Six places Wikidata has no point for | Looked up once by name with [Nominatim](https://nominatim.org) | © OpenStreetMap contributors, ODbL |

Every municipality and city kept has coordinates - the build stops rather than
write a file where one doesn't, or where one lands outside the Philippines, so
every place in the dropdown can be registered. Cities are shown as
"Dagupan City" whichever way PSGC spells them.

The build reads the whole country and then keeps only the service area, so
widening it later needs no new source of data.

Distances are "as the crow flies" between two cities' centre points, not driving
distances, and two people in the same city are shown as "same municipality/city".

## Rebuilding it

```bash
cd server
node scripts/buildLocations.js
```

Downloads are cached in `data/.cache/` (git-ignored), so a re-run is quick and
polite to the public servers. Delete the cache to refresh from scratch. The
PSGC snapshot behind `psgc.gitlab.io` predates a few 2023-24 changes (the
Negros Island Region, the split of Maguindanao), so those follow the older
hierarchy.

## File format

```jsonc
{
  "serviceArea": { "provinceCode": "0105500000", "province": "Pangasinan", "country": "Philippines" },
  "provinces": [["0105500000", "Pangasinan"]],
  // code, name, type, province code, latitude, longitude
  "cities": [["0105522000", "Lingayen", "municipality", "0105500000", 16.01667, 120.23333]]
}
```
